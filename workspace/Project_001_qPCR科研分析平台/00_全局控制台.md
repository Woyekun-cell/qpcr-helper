# qPCR 科研分析平台全局控制台

## 项目目标

构建公开可访问、账户数据隔离的 qPCR 分析平台。输入逐孔 Ct/Cq 后完成透明 QC、2^-ΔΔCt、实验设计驱动统计、多重比较和 Nature 风格科研图。

## 固定规则

- 数据单位为孔；技术重复先汇总，统计 `n` 只计算生物学重复。
- 首版只支持单内参；不静默删除异常值，不把推荐方法描述为唯一正确方法。
- 统计在 ΔCt/模型尺度完成，图中展示反变换倍数与 95% CI。
- 游客数据长期仅存浏览器；登录数据受数据库和对象存储双重 RLS 保护。
- 科研图只由 R 生成；优先 PDF/SVG 可编辑矢量输出。
- 页面、图形和文档少标题、少装饰；每个结果可追溯至输入孔和参数版本。

## 技术边界

Next.js/TypeScript 负责产品界面和 API；R Plumber 负责统计和绘图；Supabase 负责认证、数据库与文件；部署目标为 Vercel 与 Render/Railway。
