# qPCR Helper 全局控制台

## 项目目标

构建公开可访问、账户数据隔离的 qPCR 分析平台。输入逐孔 Ct/Cq 后完成透明 QC、2^-ΔΔCt、实验设计驱动统计、多重比较和 Nature 风格科研图。

## 固定规则

- 数据单位为孔；技术重复先汇总，统计 `n` 只计算生物学重复。
- 首版只支持单内参；不静默删除异常值，不把推荐方法描述为唯一正确方法。
- 统计在 ΔCt/模型尺度完成，图中展示反变换倍数与用户确认的 CI。
- 游客原始 Ct 长期仅存浏览器；服务端只留请求哈希和衍生结果 1 小时。登录数据受数据库和对象存储双重 RLS 保护。
- 科研图只由 R 生成；常规图用 ggplot2，热图用 ComplexHeatmap，优先 PDF/SVG 可编辑矢量输出。
- 默认投稿图为柱+独立点+95% CI；星号基于当前比较族的校正后 p，精确 p 保留在图注/表格。
- 期刊、莫兰迪、马卡龙、色觉安全、渐变、自定义各提供 8 套色板；支持 2–8 色编辑与宽高分级选择。
- 绘图参数变化后调用轻量预览接口自动重绘，不重复统计；当前样式同步至导出请求。
- 页面、图形和文档少标题、少装饰；每个结果可追溯至输入孔和参数版本。

## 技术边界

Next.js/TypeScript 负责产品界面和 API；R Plumber 负责统计和绘图；Supabase 负责认证、数据库与文件；生产环境部署于 Railway。

## 当前状态

界面收敛为“数据录入、分析与作图”两区；支持 Tukey 等方法说明、小提琴叠加箱线、可调样本点、单色系渐变、单图下载和可选科研包。代码同步至私有 GitHub 仓库，公开站点由 Web 与 R 两个隔离服务组成。
