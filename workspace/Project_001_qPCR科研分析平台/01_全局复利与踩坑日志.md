# 全局复利与踩坑日志

## 可复用经验

- 先确认实验单位、配对关系和比较族，再推荐检验；不能只靠正态性检验选方法。
- ΔΔCt 对照组几何均值为 1；统计误差不能直接在算术倍数尺度机械传播。
- 技术重复离散阈值没有跨平台通用值；默认报告，不自动排除。
- Nature 风格核心是可读性、可编辑矢量、准确 `n`、误差定义与统计信息，不是装饰模板。
- 示例数据需覆盖实验设计，固定 Ct 与预期效应，并同时提供生物学、技术重复。
- API 日志不得记录 Ct 请求体；导入内容需防 CSV 公式注入和标签代码注入。

## 当前避坑

- 不支持多内参时必须提示 MIQE 风险，不能暗示单内参总是充分。
- 两个 p 值一个显著一个不显著，不等于效应之间存在差异；两因素必须检验交互。
- 游客本地保存不等于从不传输；服务端分析的短暂传输和清理期限必须写清楚。
- 修改分析参数必须生成新版本，避免覆盖可复核结果。
- Vercel 多实例不能把游客任务只放进程内存；线上用服务端令牌哈希表与 Cron 清理，本地才回退内存。
- npm `xlsx@0.18.5` 有高危漏洞且无 npm 修复版；改用 `papaparse` 与 `read-excel-file`。
- R PDF 常以 1 pt 字体配合变换矩阵，纯 `Tf` 扫描会误报；仍须结合源码字号、可编辑文本和最终尺寸目视检查。
- `confidenceLevel` 不能只停留在 UI；模型 CI、图误差线、图注、Methods 和重绘脚本必须同源。
- 同一生物学重复跨分板时可能有多个 `sampleId`；必须按 `biologicalReplicateId` 汇总，防止伪重复。
- 移动端不能只检查页面总宽；顶栏、图形工具栏和宽表需分别验证换行与内部滚动。
- 显著性括号必须使用校正后 p；`* / ** / *** / ****` 阈值为 0.05/0.01/0.001/0.0001，不能替代精确 p。
- Tukey 用于等方差 ANOVA 的全部两两比较；对照比较用 Dunnett，不等方差全部两两用 Games–Howell，不能把 Tukey 当通用默认。
- 多基因结果中的 `n` 要按组和独立实验单位去重，不能按基因行数累加。
- 图形选项只触发预览，不重跑统计或跳页；预览与导出必须同源。
- 热图色阶读取当前双端颜色，以白色为零点；单元格用固定物理尺寸和黑边，避免拉伸。
- JSON `null` 进入 R 行转换时须标准化为 `NA`；否则与标量列组合会触发 1/0 行数冲突。
- 内参角色固定但名称可选；界面按用户习惯直接显示 β-actin。重命名基因/组时必须同步逐孔数据和统计配置。
