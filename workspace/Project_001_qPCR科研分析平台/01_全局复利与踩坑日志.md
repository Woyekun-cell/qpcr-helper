# 全局复利与踩坑日志

## 可复用经验

- 先确认实验单位、配对关系和比较族，再推荐检验；不能只靠正态性检验选方法。
- ΔΔCt 对照组几何均值为 1；统计误差不能直接在算术倍数尺度机械传播。
- 技术重复离散阈值没有跨平台通用值；默认报告，不自动排除。
- Nature 风格核心是可读性、可编辑矢量、准确 `n`、误差定义与统计信息，不是装饰模板。
- API 日志不得记录 Ct 请求体；导入内容需防 CSV 公式注入和标签代码注入。

## 当前避坑

- 不支持多内参时必须提示 MIQE 风险，不能暗示单内参总是充分。
- 两个 p 值一个显著一个不显著，不等于效应之间存在差异；两因素必须检验交互。
- 游客本地保存不等于从不传输；服务端分析的短暂传输和清理期限必须写清楚。
- 修改分析参数必须生成新版本，避免覆盖可复核结果。
